# Chronicle of Light

Final Fantasy 1-style modular RPG (World Map stage 1).

**Play:** https://supcsiteamgeng1.github.io/chronicle-of-light/

## Structure
- `index.html` — game shell
- `js/` — modular scripts (state, jobs, monsters, world, town, battle, render, ui, main, assets)
- `CONTRACT.md` — shared data contract

Push to `main` to redeploy via GitHub Pages.
